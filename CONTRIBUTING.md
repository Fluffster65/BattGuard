# Contributing

When adding a new part to the shared KiCad library:

- Add/update the symbol in `board/libs/symbols/TeamLib.kicad_sym`.
- Add/update the footprint in `board/libs/footprints/TeamLib.pretty`.
- Add the 3D model file in `board/libs/3dmodels/`.
- Verify the symbol, footprint, and 3D model load correctly in KiCad.
- Commit and push directly to this repository (no submodules involved).
